## Why StrideZero?

Most fitness trackers harvest your data and bloat your phone. StrideZero is built differently. It is a strictly **private-first** application engineered for extreme performance and absolute data ownership. Featuring a custom "Stride Blue" deep navy UI with highly customizable palettes (Ocean, Velocity, Violet, Sunset), it delivers native mapping and fluid animations in a remarkably tiny package.

## ✨ Key Features

### 🗺️ Smart Navigation & Goal Routing
* **Intelligent Route Generation:** Don't just pick a destination. Tell the app you want a "10,000-step walk" or a "60-minute ride," and it instantly generates a custom loop using Valhalla multi-location routing.
* **Native MapLibre Engine:** Silky smooth, high-performance vector map rendering that handles both online and completely offline modes without relying on clunky web views.
* **Intelligent Tracking:** GPS-first location with cell/Wi-Fi fallback and a strict movement-evidence gate to prevent stationary GPS wander.

### 🛡️ Privacy & Data Ownership
* **100% Local Data:** Your history, route points, activity metrics, and GPX 1.1 exports never touch a developer cloud.
* **Encrypted Backups:** PIN-encrypted `.szbackup` transfer of your complete history and settings.
* **Storage Independence:** Save backups to Google Drive, OneDrive, Dropbox, or local storage without needing a StrideZero server account.

### 🏃‍♂️ Immersive UI & Tracking
* **7 Dynamic Workout Modes:** Track walking, running, cycling, and more with distinct, fluid animated vector icons and seamless screen transitions.
* **Distraction-Free Mode:** Active sessions open a live navigation map with breadcrumb tracking, phone-heading camera options, and a focused UI that hides clutter while you move.
* **Hardware Optimized:** Leverages your phone's built-in step counter with an accelerometer/gyroscope fallback to preserve battery.

### 🧠 Stride AI & Media Integration
* **Stride AI:** Deterministic, private rules-and-metrics coaching processed entirely on your phone (no login or internet required).
* **Gemini Mode (Optional):** Advanced AI analysis using your own user-supplied API key, safely secured locally on your device.
* **Smart Media:** Built-in Android media controls with direct launch buttons for YouTube and YT Music.
* **Voice Cues:** Local Android text-to-speech cues for directions, intelligently pausing when you are stationary.

## 🛑 Honest Limits

Transparency is a core feature of this project:
* **No Cloud Backend:** There is no developer-operated cloud account. Automatic cloud syncing across devices is intentionally unsupported to maintain absolute privacy.
* **Media Controls:** Requires you to explicitly grant Android Notification access to control your active audio sessions natively.
* **Offline Maps:** Saved route geometry is available offline, but rendering fresh street maps and Esri satellite imagery requires an active internet connection.
